# Honnan vettük a módszert

A folyamat szerkezete (fázisok és kapuk, szigorúsági szintek, prototípus- és vertical slice jelentés, játékteszt-jelentés,
terjedelem-ellenőrzés, a GDD rendszerlap szakaszai, a pillérek próbái) a **Claude Code Game Studios** nyílt forrású csomag
módszereire épül: https://github.com/Donchitos/Claude-Code-Game-Studios (MIT licenc). A szövegeket a beeco saját szavaival,
a beeco oktatójátékaira szabva írtuk át; kódot, ágenseket, motorfüggő részeket (Godot, Unity, Unreal) nem vettünk át.

A beeco-saját részek:
- a `docs/jatektervezes.md` elvei és tesztelői tanulságai;
- a beeco-szelektalj „Nagy teszt” protokollja (`~/CLAUDE/beeco-szelektalj/docs/teszt-terv.md`);
- a tartalom- és forrásszabály (tény csak forrással, `HIÁNYZIK`, `JAVASLAT – jóváhagyásra vár`);
- az oktatójáték-réteg (tanulási cél ↔ mechanika, elő/utókérdés, rétegzett szöveg).

A hivatkozott elméleti fogalmak (MDA, önmeghatározás-elmélet, flow, belső integráció) az `oktato-jatek.md` végén vannak,
saját összefoglalóként, idézet nélkül.
